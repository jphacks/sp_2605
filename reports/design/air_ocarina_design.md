# エア・オカリナ 本体デザイン（M02）

記入：10/17 KatoRyunosuke（Claude と相談して整理）
状態：**工作開始用に確定**。保留の項目は下の「保留」を参照

図：[air_ocarina_design.svg](air_ocarina_design.svg)

## 全体像

段ボール箱の中に 500ml の炭酸用ペットボトルを横倒しで入れ、ボトルを「息の部屋」にする。
ストローで吹くとボトルの中の圧が上がり、DPS368 が気圧の変化を測る。息は小さな排気穴から抜ける。
タッチは PSOC 4100T Plus から導線で延長した電極を、フタの前側に貼って行う。

## 決定事項

| 部分 | 内容 |
|---|---|
| 本体 | 段ボールで組み立てる箱（目安：長さ 28 × 幅 13 × 高さ 11cm）。フタは後ろの1辺だけテープで留めて開閉できるようにする |
| 息の部屋 | **炭酸用** 500ml ボトル（普通のボトルは握ると圧が変わるため不可）。仕切り2枚（半円の切り込み）で固定 |
| 吹き口 | キャップに短く切った「受け口ストロー」をホットボンドで固定。同じストローの先をつぶして差し込む（使い捨て・人ごとに交換）。差し込む側は曲がるストローで口の高さに合わせる。受け口はボトルの中に突き出さない |
| 気圧センサー | DPS368 2GO はボトルの**底の上側**からセンサー端だけ差し込み、ホットボンドで密閉。USB・マイコン部分は外。**センサーの穴にのりをかけない** |
| 排気 | ボトルの底の下側に穴を1つ（最初は約 2mm、計測を見て広げる）。負荷は穴の大きさで決まる。閾値は演奏前の自動キャリブレーション＋ユーザー設定（ソフト側で実装） |
| タッチ | PSOC はボトルの上に置き、上面の窓から見せる。電極は銅テープ（なければアルミテープ）を直径 1.5cm の丸に切り、フタの前側に弧の形で並べる。電極どうしは 1cm 以上離す。表面は透明テープで覆う |
| 配線 | 導線（ジャンパーワイヤー）は基板のピンに差し込むだけ。電極側は被覆をはがしてテープを折り返して挟み、透明テープで押さえる。導線は 10〜15cm 以内で箱に固定、USB ケーブルとは離す。ほかの電極の下を通さない |
| 出口 | USB ケーブル2本と排気はすべて**後ろ**から出す |
| 見せ方 | 上面に窓（約 15 × 10cm）、観客側の側面に窓（約 24 × 7cm、縁 2cm）。どちらもクリアファイルを裏から貼る。中の部品に小さなラベルを貼り、配線はまとめる。後面に作品名を貼る |
| 持ち方 | 机に置いて演奏できる（底に滑り止め）。手で持つ場合は利き手でタッチ、反対の手で支える |
| ステージ | 演奏者は観客に対して横向き。窓のある側面を観客に向ける。客席から見えにくい場合はスマホ映像などで臨機応変に対応 |

## 保留

- **指で何をするか（曲モード・自由演奏など）**：ゲーム案（`game_proposal.md`）・`docs/SPEC.md` と合わせて決める
- **電極の数と並べ方**：最大5個。H08 時点で外付け電極4つ（P2.3 / P2.0 / P2.1 / P2.2 ＝ 指穴1〜4）が動作。図では4つ＋任意の5個目（前面・親指用）
- **側面の窓を開ける側**：本番で演奏する人がタッチに使う手の**反対側**。演奏者が決まるまで切らずに残す

## 作る順番

1. 材料をそろえる（M01）：炭酸用 500ml ボトル、ストロー（普通・曲がる）、段ボール、クリアファイル、ホットボンド、銅テープ or アルミテープ、ジャンパーワイヤー、透明テープ、マスキングテープ、布テープ、滑り止め、カッター
2. ボトル（息の部屋）：キャップに受け口ストロー → 底の上側に DPS368 のスリット・密閉 → 底の下側に排気穴 2mm
3. このボトルで息の値を確認し、排気穴の大きさを決める（Hi6to の PC で計測）
4. 箱：6枚切り出し → 5枚を組み立て → フタを後ろ1辺で留める → 仕切り2枚 → ボトルを載せて穴の位置に印 → 穴あけ（前面・後面・上面の窓）→ 滑り止め
5. 電極：フタの前側に貼る → 導線を差し込む → 感度確認（H08 をもう一度）
6. 通し確認：キャリブレーション、ストローの交換、ケーブルの抜けにくさ、ステージでの向き
