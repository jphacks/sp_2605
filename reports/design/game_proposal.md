# 提案：ゲームの内容（RPG ＋ 難易度）

記入：10/17 oira0822（Claude と相談して整理）
状態：**提案（未決定）**。結果画面のヒアリング（R01〜R04）と合わせてチームで決めたい

## ねらい

- 困りごと：スマホや作業に集中すると呼吸が浅くなる。深呼吸や呼吸法は退屈で続かない
- 毎日の義務にはしないが、「つい吹きたくなって、結果的に習慣になる」形にしたい
- 今の仕様（1フレーズ ＝ 1回の吐く息、フレーズごとの安定度）をそのまま使い、ゲームとして続ける理由を足す

## 1. 基本のルール

- **1戦闘 ＝ 1曲**
- **1フレーズ ＝ 1回の吐く息**：吐いている間だけ曲が進む（今の仕様どおり）
- **指穴は4つ**：光るガイドで次に押す穴がわかる

## 2. ストーリーモード（RPG）

- **敵**
  - 敵ごとに曲が違う
  - 曲の難しさ ＝ 敵の強さ（例：スライム＝きらきら星、ボス＝よろこびの歌）
  - 敵は攻撃してこない（焦ると呼吸が浅くなるので、落ち着いて吹けるように）
- **倒し方**
  - 安定して吹けたフレーズほど、敵のHPを大きく削る（フレーズごとの安定度を使う）
  - 曲の最後にHPが0になっていれば勝利
- **負けたとき**
  - ゲームオーバーにはしない
  - 同じ難易度で再挑戦するか、難易度を一つ下げるかを選ぶ
  - 「一つ下げてみる？」とすすめる表示を出す
- **最初の敵**：デモで初めての人でも必ず勝てる強さにする

## 3. 難易度（4段階）

| 難易度 | 指穴 | 安定度の基準 |
|---|---|---|
| beginner | どの穴を押しても正しい音 | ゆるめ |
| normal | どの穴を押しても鳴る。ガイドどおりに押すとボーナス | ふつう |
| hard | 正しい穴を押さないと鳴らない | ふつう |
| expert | 正しい穴が必須。光るガイドなしにしてもよい | 厳しい |

- beginner・normal は「呼吸」が中心、hard・expert は「呼吸＋指」の難しさ
- hard・expert は SPEC.md の将来機能「チャレンジモード（正しい穴でないと鳴らない）」にあたる
- 各難易度の基準値は、メンバーが何回か吹いた安定度の記録を見て決める

## 4. トレーニングモード（ストーリーとは別枠）

- 曲に縛られない呼吸の課題（例：ロングブレス＝8秒以上吐き続ける）
  - 曲はフレーズの長さが決まっていて「長く吐く」課題と合わないので、別枠にする
- 達成するとバッジやパッシブがもらえる
- 自己ベスト（最長の吐く息・最高の安定度）を記録

## 5. 成長の仕組み

- **経験値とレベル**
  - 息の質がよいほど多く入る
  - 難易度が高いほど多く入る
- **武器 ＝ 楽器**
  - 武器によって音色と攻撃の性質が変わる
    - 笛：ふつうの攻撃
    - オルゴール：安定度が高いとダメージが大きい
    - ラッパ：長く吐くほどダメージが大きい
  - 曲のクリアや敵を倒すことで手に入る
- **パッシブ（特殊能力）**
  - トレーニングでの達成で解放（例：ロングブレス達成 → 長く吐くと追加ダメージ）
  - 曲のクリアで解放（例：hard 以上でクリア → 特定の能力）

## 6. そのほかの継続の仕組み（候補）

- 自己ベストの更新演出
- ゆるい連続記録（「今週3回吹けた」のように週単位）
- 作業タイマー連携（25分作業したら「1曲吹こう」と声をかける）

## 7. 作る順番（案）

- **MVP**：敵1体・HPゲージ・フレーズごとの安定度でHPが減る・勝利画面。難易度は beginner と normal
- **できれば**：敵2〜3体（曲を増やす）、レベルと経験値
- **余裕があれば**：hard・expert（タッチの感度が安定してから）、武器、パッシブ、トレーニングモード

## 検討して見送った案（参考）

コンティニュー時に同じ曲を最初から吹き直す問題への対策として検討したが、難易度を下げられる仕組みで解決するため見送り。

- 安定しなかったフレーズだけ吹き直す → 曲の流れがなくなってつまらない
- とどめの1フレーズを追加する → わざわざ追加するほどではない
- コンティニューで敵が弱る／星0で先に進める → 次のステージとの釣り合いが崩れる
- 2回目はテンポや音色を変える → 作る手間が大きい
