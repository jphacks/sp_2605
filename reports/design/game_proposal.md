# パターン1：発表用

**流れは「難易度を選ぶ → 演奏（戦闘） → 結果発表」の3画面だけ。**

## 1. 作るもの・作らないもの

| 作る | 作らない |
|---|---|
| 難易度選択画面 | 2体目以降の敵、ステージの選択 |
| 敵1体との戦闘（演奏中にダメージが反映される） | レベル・経験値 |
| 結果発表画面 | 武器（楽器）の解放・音色の切り替え |
| | パッシブ、トレーニングモード |

## 2. 難易度選択画面

- beginner・normal・hard・expert の4つを表示
- 発表で選べるのは **beginner と normal**。hard・expert は「準備中」として表示だけ（指穴の正解判定が必要なため。時間があれば有効にする）

| 難易度 | 指穴 | 判定の基準 |
|---|---|---|
| beginner | どの穴を押しても正しい音 | ゆるめ |
| normal | どの穴を押しても鳴る。ガイドどおりに押すとボーナス | ふつう |

## 3. 演奏（戦闘）画面

- **敵は1体**（王道RPGの敵。画面の上に表示、HPゲージ付き）
- **曲は約60秒**（下の「曲と時間」を参照）
- **1フレーズ ＝ 1回の吐く息**。吐き終わるたびに、そのフレーズを判定してダメージを与える
- **判定は3段階**：PERFECT・GOOD・MISS（フレーズの安定度で決める。基準は難易度ごとに変える）
- **途中で息が切れたら**、そのフレーズは MISS で次のフレーズへ
- 画面に出すもの
  - 次に押す指穴のガイド（光る）
  - フレーズごとの判定とダメージの数字（例：「PERFECT 25」）
  - フレーズの間の「すって…」の合図
  - 敵のHPゲージ（ダメージで減る）

### ダメージとHP（仮の数値。実際に吹いて調整する）

- 敵のHP：100
- PERFECT：25、GOOD：17、MISS：0（normal でガイドどおりに押したらボーナス +3 など）
- きらきら星（6フレーズ）の場合
  - 全部 GOOD なら 102 で**ギリギリ勝てる**
  - MISS が1回あっても、PERFECT が2回あれば勝てる
- 発表では審査員やメンバーが beginner で**勝てる**ように調整する

### 曲と時間（約60秒にする）

今の曲データ（`app/web/songs.js`）をもとに計算した目安。吸う間を1フレーズあたり3〜4秒とした。

| 曲 | フレーズ数 | テンポ | 吐く時間 | 合計の目安 |
|---|---|---|---|---|
| きらきら星 | 6 | **BPM 90 に下げる**（1フレーズ約5.3秒） | 約32秒 | 約55〜60秒 |
| よろこびの歌 | 8 | 今の BPM 120 のまま（1フレーズ約4秒） | 約32秒 | 約55〜60秒 |

- どちらの曲にするかは未決定（きらきら星は短くて確実、よろこびの歌は盛り上がる）
- きらきら星はテンポを下げると1回に長く吐くことになり、「深呼吸」の説明にも合う

## 4. 結果発表画面

- **勝敗**：勝利（敵が倒れて消える）／敗北（「もう一度」「難易度を下げる」を選べる）
- **点数**：判定から計算（例：PERFECT 100点・GOOD 60点・MISS 0点 の平均）
- **判定の内訳**：PERFECT ○回・GOOD ○回・MISS ○回
- **呼吸のデータ**：安定度、吹く前と後の変化
- 言葉のトーンは**落ち着いた**ものにする（例：「深い呼吸ができました」）

# パターン2：作りたいゲーム（本来の構想）

## 1. 基本のルール

- **世界観**：王道のRPG。勇者が楽器を武器にモンスターを倒す
- **1戦闘 ＝ 1曲**、**1フレーズ ＝ 1回の吐く息**
- **指穴は4つ**：光るガイドで次に押す穴がわかる

## 2. ストーリーモード

- **ステージ構成**：基本は1ステージ ＝ 敵1体 ＝ 1曲。**ボスは1体で長めの曲**
  - 例：雑魚＝きらきら星、ボス＝よろこびの歌
- **曲の難しさ ＝ 敵の強さ**
- **敵は攻撃してこない**（焦ると呼吸が浅くなるので、落ち着いて吹けるように）
- **倒し方**：フレーズごとの判定（PERFECT・GOOD・MISS）でHPを削り、曲の最後にHPが0なら勝利。倒した敵は消える
- **途中で息が切れたら**、そのフレーズは MISS で次へ
- **負けたとき**：ゲームオーバーにはせず、「もう一度」か「難易度を一つ下げる」を選ぶ
- **次のステージへの条件**：どの難易度でも勝てばOK
- 最初の敵は、初めての人でも必ず勝てる強さにする

## 3. 難易度（4段階、戦闘の前に毎回選ぶ）

| 難易度 | 指穴 | 判定の基準 |
|---|---|---|
| beginner | どの穴を押しても正しい音 | ゆるめ |
| normal | どの穴を押しても鳴る。ガイドどおりに押すとボーナス | ふつう |
| hard | 正しい穴を押さないと音が鳴らない | ふつう |
| expert | 正しい穴が必須。光るガイドなしにしてもよい | 厳しい |

- hard・expert で間違った穴を押すと音が鳴らない。その音の分を**ダメージなしにするか**は、試したときの成功率を見て決める
- hard・expert は SPEC.md の将来機能「チャレンジモード」にあたる
- 各難易度の基準は、メンバーが何回か吹いた安定度の記録を見て決める

## 4. 成長の仕組み

- **経験値とレベル**
  - 息の質がよいほど、難易度が高いほど多く入る
  - レベルが上がると**少しだけ攻撃力が上がる**（上がりすぎると難易度を選ぶ意味が薄れるので小さめ）
  - あるレベルに達すると**新しい曲や武器が解放**される
- **武器 ＝ 楽器**：笛・オルゴール・ラッパなど。**音色だけが変わる**（性能は同じ）

## 5. リザルト画面

- 勝敗と点数
- 獲得した経験値とレベル（レベルアップ、解放されたもの）
- 呼吸のデータ（安定度、吹く前と後の変化）

## 6. 余裕があれば作るもの

- **トレーニングモード**（ストーリーとは別枠）
  - 曲に縛られない呼吸の課題（例：ロングブレス＝8秒以上吐き続ける）
  - 曲はフレーズの長さが決まっていて「長く吐く」課題と合わないので、別枠にする
  - 自己ベスト（最長の吐く息・最高の安定度）を記録
- **パッシブ（特殊能力）**：トレーニングの達成や、曲のクリア（hard 以上など）で解放
- **そのほかの継続の仕組み**：ゆるい連続記録（週単位）、作業タイマー連携

## 7. 検討して見送った案（参考）

コンティニュー時に同じ曲を最初から吹き直す問題への対策として検討したが、難易度を下げられる仕組みで解決するため見送り。

- 安定しなかったフレーズだけ吹き直す → 曲の流れがなくなってつまらない
- とどめの1フレーズを追加する → わざわざ追加するほどではない
- コンティニューで敵が弱る／星0で先に進める → 次のステージとの釣り合いが崩れる
- 2回目はテンポや音色を変える → 作る手間が大きい
