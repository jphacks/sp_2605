# シン呼吸 〜吹くだけで呼吸が整う楽器〜

[![デモ動画](https://img.youtube.com/vi/Ulbk4dHBSuo/maxresdefault.jpg)](https://youtu.be/Ulbk4dHBSuo)

**デモ動画**：https://youtu.be/Ulbk4dHBSuo

## 製品概要

**呼吸 × Tech**：ストローで吹くと、吐いている間だけ曲が進む楽器。演奏するうちに、自然とゆっくり深い呼吸になります。

### 背景(製品開発のきっかけ、課題等）

現代のスマートフォンユーザーやデスクワーカーの多くは、使っているあいだ前かがみの悪い姿勢になりがちで、そのせいで呼吸が浅くなってしまうことがあります。画面に集中すると深い息（ため息）が減るという研究もあります[1]。浅い呼吸は自分では気づきにくく、「深呼吸をしよう」と思っても、なかなか習慣にはなりません。

そこで、作業や勉強の合間に**楽しみながら一度深呼吸をする**きっかけを作ることにしました。日々の浅くなりがちな呼吸のサイクルに深呼吸というアクセントを入れて、正常な呼吸のサイクルへの改善を促すことが、このプロジェクトの目的です。

<sub>[1] Honma ら (2022) *Scientific Reports*（詳細：[reports/research/background_references.md](reports/research/background_references.md)）</sub>

### なぜ楽器なのか

既存の楽器は、指使いや音程の練習が必要で、初心者がすぐに演奏するのは難しいものです。そこで、**誰でも簡単に演奏できる楽器**を作りました。演奏に最低限必要なのは呼吸だけなので、**呼吸だけでも演奏できる**ようにしています（指穴は、押すと音がきれいになる・判定が上がる「上達の要素」です）。

### なぜゲームにしたのか

深呼吸で一番の問題は、続かないことです。体に良いと分かっていても、深呼吸だけを毎日続けるのは難しいものです。そこで、**シン呼吸を継続して使ってもらえるように、ゲームの要素を取り入れました**。曲を最後まで吹ききる、敵を倒す、レベルを上げる、息のレコードを集める、といった楽しみが、毎日使い続ける理由になります。

### 想定するユーザー

作業の合間に休憩をとる、学生やデスクワーカーです。休憩中にゲームをしたり音楽を聴いたりするだけでは、気持ちの息抜きにはなっても、体はリラックスしません。シン呼吸を使えば、**気持ちの息抜きに加えて、深い呼吸による体のリラックス**も得られます。

### 製品説明（具体的な製品の説明）

段ボールの本体の中に、炭酸用のペットボトルで作った「息の部屋」があります。ストローで吹くと部屋の気圧が上がり、それを気圧センサー（DPS368）で読み取ります。本体の表面には、タッチセンサー（PSOC 4100T Plus）につながった4つの指穴があります。

PC のブラウザに表示されるゲームでは、**1フレーズ ＝ 1回の吐く息**です。

1. 「すって…」の合図で鼻で息を吸う
2. ゆっくり吐いている間だけ、曲（きらきら星・よろこびの歌）が進んで音が鳴る
3. 画面で光った番号の指穴を押すと、きれいな音になる
4. 一息ついたら、次のフレーズへ

吐いた息の長さと安定度（ぶれの少なさ）でフレーズごとに判定し、RPG の敵にダメージを与えます。演奏が終わると、その回の呼吸が1枚の「息のレコード」として残ります。

**安定度の計算**（[app/server/breath.py](app/server/breath.py)）

1回の吐く息の間に記録した「基準からの気圧の変化」（約3回/秒）から、吹き始めと吹き終わりの各2割を除いた真ん中の値を使い、

> 安定度 ＝ 1 − 標準偏差 ÷ 平均（0 未満は 0）

で計算します。一定の強さで吐けているほど 1（100%）に近づきます。フレーズの判定には、そのフレーズの間の息の安定度の平均を使います。

### 特長

#### 1. 吹くだけで、自然と深い呼吸になる

「ゆっくり長く、一定の強さで吐く」ほど、曲がきれいに長く鳴り、判定も良くなります。呼吸法を覚えなくても、楽器を上手に吹こうとするだけで深呼吸になります。吐き方は、ふつうの笛のような音程の操作ではなく「長さ」と「安定度」で評価するので、楽器の経験がなくても演奏できます。

#### 2. 指で弾く楽しさと、続けたくなる RPG

4つの指穴と画面のリズムの目印は、同じ番号・同じ色で対応しています。難易度は4段階あり、初心者はどの穴でも鳴り、上級者は正しい穴を押さないと鳴りません。呼吸が安定していると攻撃が強くなり、アバターにオーラがまとい、経験値でレベルが上がります。**負けても曲は最後まで進む**ので、深呼吸の途中で終わることはありません。

#### 3. 毎回の呼吸が「息のレコード」になって残る

1回の演奏が1枚のレコードになります。1本の輪が1回の息で、輪の太さは吐いた秒数、色は安定度を表します。レコード棚で前回と比べたり、その回の演奏を再生したりでき、「次はレコードを埋めよう」という目標につながります。

#### 4. 曲の中で、いろいろな吐き方の訓練ができる（これから入れる予定の機能）

※ この特長は、まだ実装していません。これから入れる予定の機能です。

フレーズによって求められる吐き方が変わるので、同じ強さで吐き続けるだけの単調な訓練になりません。

- **つなげて吐くフレーズ**：難易度 expert では、1フレーズごとではなく2フレーズ分を一息で吐き続けることが求められます
- **強く吐くフレーズ**：気圧センサーの判定の基準（閾値）を上げたフレーズでは、ふだんより強い息で吹かないと音が鳴りません
- **長く吐き続けるフレーズ**：できるだけ長く息を吐き続けるほど、音が伸びて評価が上がります

ステージごとに、こうした吐き方を取り入れた曲を用意することで、遊びながら「長く」「強く」「つなげて」といったいろいろな種類の呼吸の訓練ができます。

### 解決出来ること

- 浅くなりがちな呼吸に、**楽しみながら深呼吸をするきっかけ**を作れる
- 呼吸の長さ・安定度を毎回記録して見える形にするので、自分の呼吸の変化に気づける
- ゲームとレコードの収集で、深呼吸を「続ける理由」が生まれる

### 今後の展望

- 本体の小型化と、スマートフォンだけで遊べる版（PC なしで使えるように）
- 吹き口の衛生面の改善（使い捨てのストロー以外の方法）
- ペットボトル内の結露の対策（吐く息の水分がボトルの中にたまり、衛生面やセンサーに影響しないようにする）
- 曲・ステージの追加、本物の楽器の音色への差し替え
- 長く続けられるように、レベルアップで新しい楽器を解放し、選んだ楽器に合わせた音色で演奏できる機能（楽器ごとの性能は同じで、音色だけが変わる）
- 吐いた息の合計時間を「息の貯金」として通貨にし、ゲーム内のアイテムと交換できる機能
- 過去の自分の演奏データが「影の勇者」として現れ、同じ曲で競える機能（他人と比べず、自分の成長が見える）
- 息のレコードの図鑑：「全部 PERFECT」「全フレーズ5秒以上」などの条件を満たすと特別なレコード（虹色など）が手に入り、図鑑が埋まっていく機能

#### 応用の可能性

シン呼吸の「ストローで長く吐く」動作と、吐く強さを測れる仕組みは、ゲーム以外にも次の2つの方向に広げられると考えています。どちらもまだ確かめていない構想です。

**① 医療・リハビリでの応用**

1つ目は、飲み込みのリハビリ（誤嚥の予防）です。誤嚥性肺炎は日本の死因の第6位で（2024年、63,665人。厚生労働省 人口動態統計）、飲み込みのリハビリでは負荷をかけて息を吐く訓練が使われています。パーキンソン病の人や脳卒中のあとの人では、この訓練で飲み込みの安全性が改善したという試験があり（Troche 2010、Claus 2021）、脳卒中のあとの人では肺炎などの合併症が約半分になったという分析もあります（11試験・523人のメタ解析、Arch Phys Med Rehabil 2021）。日本摂食嚥下リハビリテーション学会の「訓練法のまとめ（2014版）」にも、ストローで長く吹く「ブローイング訓練」が載っています。一方で、こうした訓練は毎日・数週間続ける必要があり、続けにくいことが課題です。シン呼吸は吐く強さをその人に合わせて調整でき、曲が進む楽しさで毎日の訓練を続けやすくします。圧や回数が自動で記録されるので、家での訓練の様子を言語聴覚士などの医療者と共有する使い方も考えられます。退院後の在宅リハビリや、介護施設・デイケアでの体操の時間への導入を想定しています。

2つ目は、いびき・睡眠時無呼吸です。睡眠時無呼吸の人を対象にした小規模な試験では、高い負荷で息を吐く訓練を続けると、無呼吸の回数が4〜5割減りました（Erturk 2024、Kuo 2017）。負荷のないふつうの深呼吸体操ではいびきが減らなかったため（Ieto 2015）、ここでも「負荷を調整できること」と「続けられること」がシン呼吸の役割になります。CPAP などの治療の代わりではなく、自分でできることを探している人の自宅での訓練として使うことを想定しています。

**② 日常の休憩での応用**

SNS などをつい見続けてしまうことを防ぐために、将来的にはスマートフォン用のアプリを開発し、シン呼吸と連携させることを考えています。アプリが SNS のスクリーンタイムを参照し、一定の基準値に達したら自動で起動して、シン呼吸での深い呼吸を強制的に行わせます。1曲（約1分）をゆっくり長く吐いて演奏し終えるまで画面から離れる時間をつくることで、スマホを見続けるだけの休憩ではなく、効果的な休憩をとれるようにします。

**③ 集めたデータの研究・解析への活用**

シン呼吸は、演奏のたびに吐く息の圧の波形、吐く長さ、安定度、吐く力の変化を日付とともに記録しています。こうしたデータを長期間ためていくことで、呼吸の訓練をどれくらい続けると吐く力や安定度がどう変わるか、どんな人が続けやすいかといった研究や解析に使うことができます。医療・研究機関と連携すれば、①のリハビリの効果を確かめる研究の基礎データとしても活用できると考えています。

### 注力したこと（こだわり等）

* **センサーの値を「息の部屋」で安定させた**：センサーに直接吹きかけると値のぶれが大きかった（約 4Pa）ので、密閉した部屋をストローで吹く構造にしました。ぶれは約 0.4Pa まで下がり、弱い息（+120Pa 前後）と強い息（+300Pa 前後）がはっきり区別できるようになりました（[計測データ](reports/measurements/H12_sealed_bag_1017.csv)）
* **指穴の電極の配置**：はじめは、箱の横に電極を付けたほうが演奏しやすいと考えました。しかし、そこまで銅線を伸ばすと、銅線どうしが干渉して隣の穴まで反応してしまいました。そこで、銅線を短くできる位置で、電極どうしの間隔をあけて横一列に並べる今の形にしました
* **吹いていないのに反応する誤検知を減らした**：基準の気圧を少しずつ追いかけ、吐き始めと吐き終わりで別のしきい値を使っています。基準がずれたまま止まった場合は、自動で測り直します
* **呼吸として気持ちよいテンポにした**：1フレーズを約4秒（8拍）に区切り、フレーズの間は息が止まるまで待ちます。安定度は吹き始めと吹き終わりを除いて計算し、自然な強弱で減点されないようにしました
* **ハードウェアは Sense → Think → Act の流れ**：Infineon の2つのボードで息と指を読み取り（Sense）、Python で呼吸の長さ・安定度を解析し（Think）、音・ゲーム・レコードで返します（Act）

## 開発技術

### 活用した技術

#### API・データ

* Web Audio API（音の合成）、WebSocket（ボード → PC → ブラウザの中継）
* 遊んだ記録は PC 内のファイル（JSON Lines）に保存。ログインやクラウドは使っていません

#### フレームワーク・ライブラリ・モジュール

* Python 3（pyserial、websockets）：ボードの受信・息の判定・記録・経験値の計算
* JavaScript（ES Modules、フレームワークなし）、Canvas・SVG：ゲーム画面・演出・アバター・レコードの描画
* ModusToolbox 3.9、CAPSENSE ミドルウェア：タッチセンサーのファームウェア

#### デバイス

* Infineon KIT_DPS368_2GO（気圧センサー XENSIV DPS368）：息の強さ
* Infineon CY8CPROTO-041TP（PSOC 4100T Plus、CAPSENSE）：4つの指穴（銅・アルミテープの電極）
* 本体：段ボール、炭酸用 500ml ペットボトル、ストロー
* PC（Windows）と Chrome / Edge

## 動かし方

Windows の PC に Python 3.10 以上を入れ、`setup.bat`（最初の1回）→ `start.bat` をダブルクリックすると、ブラウザで http://localhost:8000/ が開きます。ボードがなくても、スペースキー長押し（吐く）と 1〜4 キー（指穴）で遊べます。詳しい手順は [docs/SETUP_MANUAL.md](docs/SETUP_MANUAL.md) にあります。
