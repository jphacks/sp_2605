# 自分のPCでシン呼吸を動かす（手作業のチェックリスト）

コマンドは使わず、**ダウンロードとクリックだけ**で進める手順です。上から順に、終わったら `[ ]` を `[x]` にしていってください。
（Claude Code に任せる場合は `docs/SETUP.md` を使う）

---

## 1. ダウンロード・インストールが必要なもの

| # | もの | 入っているか確かめる方法 | 入っていなければ |
|---|---|---|---|
| 1 | **Python 3.10 以上** | 手順3の `setup.bat` が教えてくれる | 下の「Python の入れ方」 |
| 2 | **Chrome または Edge** | Edge は Windows に最初から入っている | 不要（Edge でOK） |
| 3 | Git（リポジトリを最新にする） | すでに clone できているなら入っている | 不要 |

**入れなくてよいもの**：ModusToolbox、Arduino、J-Link、ボードのドライバ（ボードへの書き込みは Hi6to のPCで済んでいる。ドライバは Windows に最初から入っているもので動く）

### Python の入れ方（無かった場合だけ）

- [ ] ブラウザで **https://www.python.org/downloads/windows/** を開く
- [ ] 一番上の **「Latest Python 3 Release - Python 3.x.x」** をクリック → ページ下の **「Windows installer (64-bit)」** をクリックしてダウンロード
- [ ] ダウンロードしたファイル（`python-3.x.x-amd64.exe`）を**ダブルクリック**
- [ ] 最初の画面の一番下、**「Add python.exe to PATH」に必ずチェック**を入れる
- [ ] **「Install Now」** をクリック
- [ ] 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
- [ ] 「Setup was successful」と出たら **「Close」**

---

## 2. リポジトリを最新にする

- [ ] いつもの方法で **pull** する（GitHub Desktop なら「Fetch origin」→「Pull origin」、VS Code なら左下の同期ボタン）
- [ ] フォルダの中に `setup.bat` と `start.bat` があることを確認する

---

## 3. セットアップ（最初の1回だけ）

- [ ] エクスプローラーでリポジトリのフォルダを開き、**`setup.bat` をダブルクリック**
  - 「Windows によって PC が保護されました」と出たら → **「詳細情報」→「実行」**
- [ ] 黒い画面に次のように出れば OK（何かキーを押すと閉じる）
  ```
  [OK] Python 3.x.x
  [OK] pyserial ...
  [OK] websockets ...
  → 準備OK。
  ```
- [ ] `[NG] Python が見つかりません` と出た → 上の「Python の入れ方」をしてから、もう一度 `setup.bat` をダブルクリック
- [ ] それ以外の `[NG]` が出た → 黒い画面の文字をスクショして Hi6to に送る

---

## 4. ボードをつなぐ（無くても動作確認はできる）

- [ ] **PSOC 4100T Plus に、指穴の電極（アルミ）を先につなぐ**
  - 指穴1 ＝ **P2.3**、指穴2 ＝ **P2.0**、指穴3 ＝ **P2.1**、指穴4 ＝ **P2.2**
- [ ] PSOC 4100T Plus を **USB Type-C** で PC に挿す（電極をつないでから挿す。挿した時に電極に合わせて自動調整するため）
- [ ] DPS368 2GO を **USB Micro-B** で PC に挿す
- COM ポートの番号は気にしなくてよい（アプリが自動で探す）

---

## 5. 起動する（毎回）

- [ ] **`start.bat` をダブルクリック**（「詳細情報」→「実行」が出たら同じように）
- [ ] 数秒でブラウザが開く（開かなければ、自分で **http://localhost:8000/** を開く）
- [ ] **画面を1回クリック**（音を出せるようにするため）
- [ ] 右上の表示を確認
  - 「センサー：接続中」→ DPS368 がつながっている
  - 「センサー：未接続」→ ボード無しでも、**スペースキー長押し＝吐く、1〜4キー＝指穴**で遊べる
- **終わるとき**：黒い画面（start.bat の画面）を閉じる

---

## 6. 動作確認

- [ ] 「はじめる」→ 難易度を選ぶ → 吹く（またはスペースキー）
- [ ] 1曲吹き終わって、**「勝利！」**と**「きょうの こきゅうが 1まいの レコードに なりました」**が出る
- [ ] 「レコード棚」を開いて、レコードをクリック →「さいせい」で音が出る
- [ ] TASKS.md の **K01** に結果を書いて push する（例：`10/17 Kato：自分のPCで起動OK。DPS368・タッチともに接続中`）

## うまくいかないとき

| 症状 | やること |
|---|---|
| `setup.bat` を開くと一瞬で消える | フォルダの場所が深すぎる／日本語が入っている可能性。スクショを送る |
| 「Windows によって PC が保護されました」 | 「詳細情報」→「実行」 |
| ブラウザで「このサイトにアクセスできません」 | `start.bat` の黒い画面が開いているか確認。閉じていたらもう一度ダブルクリック |
| 黒い画面に「ポートが使用中」のようなエラー | すでに起動している。開いている黒い画面を全部閉じてからもう一度 |
| 「センサー：未接続」のまま | USB を挿し直す。別のケーブル（データ通信用）で試す |
| 吹いていないのに反応する | 12秒ほど何もしなければ自動で直る。ボトルや袋を握らない |
| 音が出ない | 画面を1回クリックしたか。PC の音量 |
| 指穴が反応しない・反応しすぎる | 電極をつないだまま PSOC 4100T Plus の USB を挿し直す |

困ったら、**黒い画面とブラウザの画面のスクショ**を Hi6to に送ってください。

## デモの観戦（同じ Wi-Fi のほかのPCに、演奏の画面をそのまま映す）

発表で、笛をつないだPC（演奏するPC）の画面を、プロジェクターにつないだ別のPC（観戦するPC）に映すための機能です。

### 演奏するPC（ボードをつなぐPC）

- [ ] **`share.bat` をダブルクリック**（いつもの `start.bat` の代わり）
- [ ] 初めてのときだけ、Windows に **「アクセスを許可しますか？」** と聞かれる → **「プライベート ネットワーク」にチェックして「許可」**（PC の安全設定なので、そのPCの持ち主が判断する）
- [ ] 黒い画面に出る **観戦用のアドレス** をメモする（例：`http://192.168.0.12:8000/?watch=1`）

### 観戦するPC（プロジェクターにつなぐPC）

- [ ] 同じ Wi-Fi につなぐ
- [ ] ブラウザで、メモした **観戦用のアドレス** を開く（このPCにはインストール不要）
- [ ] 上に「観戦モード」の帯が出ていれば OK。**画面を1回クリック**すると、こちらのPCからも音が出る
- [ ] 演奏するPCで遊ぶと、こちらにも同じ画面がそのまま流れる（観戦側は操作できない・記録も残らない）

### うまくつながらないとき

| 症状 | やること |
|---|---|
| 観戦用のアドレスを開いても表示されない | 両方のPCが同じ Wi-Fi か確認。会場の Wi-Fi が端末どうしの通信を止めている場合は、スマホのテザリングに両方をつなぐ |
| 「アクセスを許可」を押し忘れた | Windows の設定 →「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」で Python にチェック（持ち主が判断） |
| 途中から開いたら画面がずれている | 観戦画面は、演奏を始める**前に**開いておく。ずれたら観戦側を再読み込みして、次の曲から |
| 本番でつながらない | **予備の方法**：笛のボードを、プロジェクターにつないだPCに直接挿して、そのPCで `start.bat` を起動する（ネットワークを使わないので確実） |
