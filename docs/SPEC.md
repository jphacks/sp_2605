# 仕様メモ（決まったこと・検討中のこと）

最終更新：10/17（ヒアリング第3ラウンドまで）

## コンセプト

**「呼吸を整える楽器」**：作業の合間に、時間があるときに、楽しみながら呼吸をリセットする。
吹くと曲が進み、初心者でも「曲を弾いている」楽しさを味わえる。

## 決まったこと

| 項目 | 決定 |
|---|---|
| 場面 | 作業・勉強の合間のリフレッシュ（毎日の義務ではなく、時間があるときに楽しみながら） |
| 体験の中心 | **1フレーズ ＝ 1回の吐く息**。吐いている間だけ曲が進み、一息ついて次のフレーズへ |
| 指の操作 | **案B：光るガイド＋どの穴を押しても正しい音**。正しい穴を押すと演出が出る |
| 指穴の数 | **4つ**（片手で演奏できる） |
| 構成 | **Python が中継役**：ボード →(USB)→ Python（受信・統合・分析・保存）→(PC内通信)→ ブラウザ（音・画面） |
| 記録の保存 | **Python 側のファイル**。日ごとの推移をグラフにする |
| 曲 | 著作権が切れた童謡・クラシック。**MVP は「きらきら星」**。何曲か演奏できるようにしたい |
| 発表 | 約90秒のプレゼン内で演奏する → 有名で盛り上がる曲が良い |

## 使う流れ（案）

1. 起動：Python を起動 → ブラウザで画面が開く
2. ホーム：「吹いてはじめよう」→ ストローを軽く吹くとスタート
3. 演奏：指穴の図で次の穴が光る。「すって…」→ 吐くとフレーズが流れる → 一息 → 次へ
4. 結果：**内容はチームで相談中**（TASKS.md の R01）
5. 記録：日ごとの推移グラフ（デモ用サンプルデータあり）

## 機能の切り分け

| 区分 | 機能 |
|---|---|
| **MVP（1日目に必ず動かす）** | 息の強さを読む（DPS368 → Python → ブラウザ）／吐いている間だけフレーズが進み音が鳴る（きらきら星）／指穴ガイドとタッチ読み取り（案B）／結果画面 |
| できれば（2日目午前） | 日ごとの推移グラフ／2曲目以降／正しい穴を押した時の演出 |
| 余裕があれば | 自由に吹くモード（どこを押しても外れない音階）／音色の切り替え |
| **後で作る（将来の機能）** | チャレンジモード（正しい穴でないと鳴らない）／スマホ対応 |
| 今回は作らない | ログイン・クラウド保存／SNS共有／曲を自分で追加する機能 |

## ハードウェア（受け取ったボード）

| 役割 | ボード | 状態 |
|---|---|---|
| 息 | KIT_DPS368_2GO（マイコン XMC4200 付き、USB Micro-B） | 書き込み方法を確認中（下記） |
| 指 | CY8CPROTO-041TP（PSOC 4100T Plus） | ModusToolbox でサンプルのビルド確認済み |
| 予備 | CY8CPROTO-062-4343W（PSoC 6）、KIT_PSC3M5_EVK | 使うかは未定 |

**DPS368 2GO の書き込みについて：** 現行の Arduino 用 XMC ボード定義（4.x）は XMC4200 に未対応。旧版（3.5.7）に「XMC4200 Platform 2GO」があるので Hi6to のPCに追加済み。ピン配置が同じかは要確認。だめな場合は ModusToolbox（KIT_XMC_PLT2GO_XMC4200）か、キットに最初から入っているプログラムの出力をそのまま使う方法を検討する。
