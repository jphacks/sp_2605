# ヒアリング：結果画面（演奏が終わった後の画面）

演奏が終わった後に何を見せるかを、チームで決めるためのアンケート。
**自分の欄だけ**記入して push する。全員分そろったら Hi6to と Claude でまとめて決める。

## 前提

- アプリは「作業の合間に、楽しみながら呼吸をリセットする楽器」
- 結果画面は、1曲吹き終わった直後に出る
- 使える情報：吐いた回数、1回に吐いた長さ（秒）、息の安定度（強さのぶれ）、吹く前と後の呼吸の変化、日ごとの記録

## 質問

1. **一番大きく見せたいものは？**（1つ選ぶ）
   - A. 点数（例：82点）— わかりやすく、遊びとして楽しい
   - B. やさしい言葉（例：「呼吸がゆっくりになりました」）＋数値は小さく — リフレッシュのテーマに合う
   - C. グラフ（息の強さの波など）— データ分析らしさが出る
   - D. その他（自由に）
2. **数値で見たいものは？**（いくつでも）：吐いた回数 / 1回の吐く長さ / 安定度 / 吹く前と後の変化 / 前回との比較 / その他
3. **言葉のトーンは？**：ほめる（「すごい！」）/ 落ち着いた（「深い呼吸ができました」）/ 先生っぽい（「もう少しゆっくり吐きましょう」）
4. **結果画面の後、ユーザーに何をしてほしい？**：もう1曲 / 記録を見る / 作業に戻る / その他
5. **90秒のプレゼンで、審査員にどう感じてほしい？**（自由に一言）
6. **その他、アイデアや「こういうのは嫌」があれば**
